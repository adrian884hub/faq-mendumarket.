# Mendu Market help center

Frequently asked questions page for the Mendu Market online store: payments, shipping and returns, with direct WhatsApp contact. The page content is in Spanish, for the store's customers in Argentina.

**View the page:** https://adrian884hub.github.io/faq-mendumarket./

## What it includes

- Questions grouped by topic, answered before and after the purchase
- Expandable answers to keep the page short and easy to scan
- WhatsApp contact for anything not covered
- Mobile-friendly design

## Built with

- HTML, CSS and JavaScript, no libraries
- Published with GitHub Pages
